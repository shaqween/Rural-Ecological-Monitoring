# Rural-Ecological-Monitoring

**Название датасета:** Rural Ecological Monitoring Dataset

**Источник:** Kaggle

**Ссылка на источник:**
https://www.kaggle.com/datasets/colabsss/rural-ecological-monitoring-dataset

**Автор:** colabsss

### Что является строкой

Одна строка описывает конкретное состояние окружающей среды в рамках одного экологического мониторингового наблюдения.

### Признаки

**Timestamp** — дата и время проведения экологического наблюдения.

**Region_ID** — уникальный идентификатор сельской территории или зоны мониторинга.

**Soil_Moisture** — влажность почвы, то есть содержание воды в почве, измеряемое в процентах.

**Soil_Temperature** — температура почвы, измеряемая в градусах Цельсия.

**Soil_pH** — показатель кислотности или щёлочности почвы, характеризующий её химическое состояние.

**Soil_Nitrogen** — концентрация азота в почве, влияющая на рост растений.

**Soil_Phosphorus** — содержание фосфора в почве, связанное с развитием корневой системы растений.

**Soil_Potassium** — содержание калия в почве, влияющее на устойчивость и состояние сельскохозяйственных культур.

**Air_Temperature** — температура воздуха, измеряемая в градусах Цельсия.

**Humidity** — относительная влажность воздуха, измеряемая в процентах.

**Rainfall** — количество осадков, измеряемое в миллиметрах.

**Solar_Radiation** — интенсивность солнечного излучения, поступающего на поверхность земли.

**Groundwater_Level** — уровень доступности подземных вод, измеряемый в метрах.

**Surface_Water_Availability** — доступность поверхностных водных ресурсов, измеряемая в процентах.

**NDVI_Index** — индекс состояния растительности, который характеризует степень её зелёности и позволяет оценивать состояние растительного покрова.

**Vegetation_Density** — плотность растительности, то есть доля поверхности земли, покрытая растительностью, измеряемая в процентах.

**Biodiversity_Index** — индекс биоразнообразия, характеризующий разнообразие присутствующих видов живых организмов.

**Land_Degradation_Index** — индекс деградации земель, характеризующий степень ухудшения состояния окружающей среды и земельных ресурсов.

**Crop_Yield_Potential** — потенциальная урожайность сельскохозяйственных культур, измеряемая в килограммах на гектар.

**Drought_Risk_Level** — уровень риска засухи, то есть показатель вероятности возникновения условий, связанных с нехваткой воды.

**Soil_Erosion_Risk** — риск эрозии почвы, то есть вероятность потери почвы в результате эрозионных процессов.

**Recommended_Irrigation** — рекомендуемый объём орошения, необходимый для территории, измеряемый в миллиметрах в день.

**Land_Use_Category** — категориальный показатель, определяющий подходящий тип использования сельской территории.

## Целевая переменная

**Land_Use_Category** — категориальная переменная, определяющая подходящий тип использования сельской территории.

### Ограничения и риски

Датасет создан на основе AI и IIoT-систем и, вероятно, является синтезированным. Реальные экологические связи могут быть упрощены или искажены. Возможны выбросы/аномалии, дубликаты и несогласованность единиц измерения. Есть риск дисбаланса класса.

## ПОСТАНОВКА АНАЛИТИЧЕСКОЙ ЗАДАЧИ

### Пользователь результата

Результат анализа может использовать специалист по экологическому мониторингу, исследователь или специалист, занимающийся планированием использования сельских территорий.

## Исследовательский вопрос

Можно ли по экологическим, почвенным, климатическим и гидрологическим показателям определить категорию использования сельской территории? Какие экологические характеристики наиболее связаны с выбором категории использования земель?

### Критерий успеха

Критерием успеха будет являться получение модели классификации, которая достаточно точно определяет категорию использования территории по экологическим показателям.

### Необходимые данные

Для решения задачи необходимы все 22 признака (кроме Region_ID и Timestamp, которые являются идентификаторами и временными метками) для предсказания целевой переменной Land_Use_Category.

### Аналитический подход

**Классификация**, так как в датасете присутствует категориальная целевая переменная.
